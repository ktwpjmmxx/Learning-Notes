# Experiments フォルダについて

この `Experiments` フォルダは、Google Colab 上で GPT-2 および GPT-OSS のオープンウェイトモデルを使ってチャットボットを実装した過程を整理・記録するためのフォルダです。

## フォルダ構成

- `GPT-2/` : GPT-2 モデルを用いた実験ファイルを格納  
- `GPT-OSS/` : GPT-OSS モデルを用いた実験ファイルを格納  

各サブフォルダ内には、モデルの概要や実験の手順、動作確認などをまとめたファイルがあります。  
実際のチャットボットの動作結果や詳細は各 `chatbot-test.md` に記録しています。

## 目的

異なるオープンウェイト言語モデルを用いたチャットボット実装の概要を整理し、学習や今後の実装改善に役立てることが目的です。

## 更新履歴

**2025/09/16**

### GPT-2を用いたチャットボットの制作

- Ver.1 
 - レビュー：返答があまりにも長文すぎる。内容が支離滅裂。
 - 改善案：モデルを'gpt2'から'gpt2-medium'へ変更。

- Ver.2
 - レビュー：
  - Ver.1よりもしっかりした内容の出力だがモデルが先行して会話を続けてしまう。
  - 出力冒頭でのロール指定が表示されてしまう。
 - 改善案：
 - max_length を短めに設定
 - top_k / top_p を保守寄りに調整し、脱線や過剰生成を抑制

- Ver.3
 - レビュー：
  - 質問に対する回答は得られず、2回目以降の質問にはすべてエラー
 - 改善案：
 - 生成パラメータの再調整、会話履歴・内部処理の安定化のためwith torch.no_grad(): を確実に使用

- Ver.4
 - レビュー：
  - 今までで一番自然で理想に近い出力が得られたが引き続き2回目以降のエラーが発生。
  - システムプロンプトを入力と認識してそれに対して回答していた。
 - 改善案：
  - 出力トークン数の制御 -- max_length ではなく max_new_tokens を使う。
  -  outputs = model.generate(
    inputs,
    max_new_tokens=60,  # 出力だけを制限
    ...
   )
  - すべての履歴を入れるのではなく、直近数ターンのみ保持。

- Ver.5
 - レビュー：4回以上のやりとりに対応できたが、1問1答という目的から外れてしまった。
 - 改善案：1ターン完結 - User/Assistant ラベルを廃止して、純粋な質問文だけを入力

- Ver.6
 - レビュー：3回目の回答で「I am a man.」の繰り返しループの出力が出てしまった。
 - 改善案：生成後の切り出し（入力を除いて“生成部分だけ”を取る）＋繰り返し抑制＋短文化（最初の文だけ返す） を組み合わせる

**2025/09/17**

### GPT-2を用いたチャットボットの制作day2

- Ver.6.1
 - レビュー：何回もの入力に対して一貫して1答で固定されていたので良かった。
 - 改善案：「一問一答」は維持しつつ、生成の多様性を制御パラメータで補強する

- Ver.6.2
 - レビュー：
  - 冒頭にattentionマスクが自動生成されていないという警告メッセージが表示。
  - 回答が長くなってしまい、多様すぎてしまった。
 - 改善案：
  - 生成パラメータの調整
  - attention_mask を明示的に設定

- Ver.7.0-完全版
 - レビュー：
  - 名前のみを10回端的に出力することが可能になった。
  - 最終的には「Could you tell me about your name ?」ではなく、複数の異なる
  プロンプトパターンをランダムに選択
