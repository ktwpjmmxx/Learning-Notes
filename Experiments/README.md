# Experiments - GPT Chatbot

このフォルダでは、GPT-2 および GPT-OSS を使ったチャットボットの制作実験と検証記録をまとめています。
主に Google Colab 上での試行・検証を行った内容です。

## フォルダ構成

### GPT-2
- `GPT_2_ChatBot.ipynb` : 実験用ノートブック
- `gpt2_chatbot_part1-fin.py` : 完成版スクリプト
- `about-gpt2.md` : GPT-2の概要や学習メモ
- `chatbot-test.md` : Colab上でのトライ＆エラーの記録

### GPT-OSS
- `ChatBot-OSS_ver1.0.py` : 完成版スクリプト
- `about-gptoss.md` : GPT-OSSの概要や学習メモ
- `chatbot-test.md` : Colab上でのトライ＆エラーの記録
- `screenshot/` : GUI表示のスクリーンショット

## 利用方法
1. Colab またはローカルでノートブックやスクリプトを開く
2. GPUが利用可能な環境でモデルをロード
3. スクリプトを実行して自由入力でのチャットを試す

## 注意点
- 試行錯誤の履歴は `chatbot-test.md` に記録
- 完成版コードは `*.py` にまとめています
- GUIのスクリーンショットは `screenshot/` フォルダに格納
