# Experiments フォルダについて

この `Experiments` フォルダは、Google Colab 上で GPT-2 および GPT-OSS のオープンウェイトモデルを使ってチャットボットを実装した過程を整理・記録するためのフォルダです。

## フォルダ構成

- `GPT-2/` : GPT-2 モデルを用いた実験ファイルを格納  
- `GPT-OSS/` : GPT-OSS モデルを用いた実験ファイルを格納  

各サブフォルダ内には、モデルの概要や実験の手順、動作確認などをまとめたファイルがあります。  
実際のチャットボットの動作結果や詳細は各 `chatbot-test.md` に記録しています。

## 目的

異なるオープンウェイト言語モデルを用いたチャットボット実装の概要を整理し、学習や今後の実装改善に役立てることが目的です。
