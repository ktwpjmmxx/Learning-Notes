# AI-Certifications

このリポジトリは、AI関連の資格取得に向けた学習記録とリソースを管理するためのものです。

## 📚 取得予定資格

- **生成AIパスポート** - 生成AIの基礎知識と実用的な活用方法を学ぶ資格
- **JDLA G検定（ジェネラリスト検定）** - ディープラーニングの基礎知識を問う日本ディープラーニング協会の検定

## 📁 フォルダ構成

### generative-ai-passport/
生成AIパスポート試験対策のための学習資料
- `exercises.md` - 実践的な練習問題と解答例
- `mock-tests.md` - 模擬試験問題とその解説
- `notes.md` - 試験範囲の重要ポイントをまとめた学習ノート
- `resources.md` - 参考書籍、Webサイト、公式資料などのリンク集

### jdla-g-exam/
JDLA G検定対策のための包括的な学習資料

#### study-notes/
シラバスに基づいた体系的な学習ノート
- `machine-learning-basics.md` - 機械学習の基本概念、アルゴリズム、データ処理手法
- `deep-learning-fundamentals.md` - ディープラーニングの仕組み、各種アーキテクチャ、学習手法
- `applications-and-cases.md` - AI技術の実用例、業界別活用事例、最新技術動向
- `ethics-and-society.md` - AIの社会実装課題、倫理的考慮事項、関連法規制

#### その他のフォルダ
- `exercises/` - 計算問題や概念理解のための練習問題集
- `mock-tests/` - 模擬試験問題と詳細な解答・解説
- `past-papers/` - 過去問題の分析と出題傾向対策
- `resources.md` - G検定対策に役立つ参考資料とリンク集

### shared-resources/
複数の資格で共通して活用できるリソース
- `terminology.md` - AI・機械学習関連の専門用語集
- `useful-links.md` - 学習に役立つWebサイト、動画、記事のリンク集
- `books-and-papers.md` - 推薦書籍と重要論文のリスト

### progress-tracker.md
学習進捗管理ファイル
- 各資格の学習スケジュールと進捗状況
- 理解度チェックと弱点分析
- 試験日程と対策計画

## 🎯 学習目標

1. **生成AIパスポート**: 生成AIの基本的な仕組みと実用的な活用方法を理解する
2. **JDLA G検定**: ディープラーニングの理論的基礎から実装まで幅広い知識を習得する

## 📊 進捗状況

学習の進捗状況は `progress-tracker.md` で管理しています。定期的に更新し、効率的な学習を心がけています。
