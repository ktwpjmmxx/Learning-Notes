#### **[Role指示]**

#### **[制約条件（Constraints）]**
**定義**: [定義・意味]
出力に条件を付けることで精度を高める
AIの出力に「枠組み（ルールや制限）」を与えることで、回答を狙い通りの形に導く手法
▪️観点
「プロンプトで制約条件を加えると何が得られるか？」
→ 出力の一貫性と再現性が高まる。
「どのような種類の制約条件があるか？」
→ 文字数・形式・内容・役割・倫理など。
「制約条件を加えるときの注意点は？」
→ 厳しすぎる制約はAIが出力不能（無回答やエラー的出力）になる。
#### **[出力形式指定]**
**定義**: [定義・意味]
表や箇条書きなどフォーマットを指定する方法
#### **[システムプロンプト]**
**定義**: [定義・意味]
AIの基本的な振る舞いを決める内部指示
**通常プロンプトとの違い**
ユーザープロンプト
　→ 利用者が毎回入力する指示文。「質問」「タスク依頼」「条件設定」など。
システムプロンプト
　→ 開発者やシステム側があらかじめ設定する指示。AIの「キャラクター」「トーン」「役割」「制限事項」を決める。
▪️観点
「システムプロンプトの役割は？」
→ AIの基本的な振る舞いや人格を定義すること。
「ユーザープロンプトとの違いは？」
→ ユーザーが直接入力するのはユーザープロンプト、開発側が内部で設定するのがシステムプロンプト。
「システムプロンプトを工夫すると何ができるか？」
→ 安定したトーン・一貫性のある応答が得られる。
#### **[リファインプロンプト]**
**定義**: [定義・意味]
初回回答をもとにプロンプトを改善する方法
リファインプロンプトとは、AIの初回出力を見てプロンプトを調整・改善し、より望ましい応答を引き出す手法

４市場への影響
・著作権者の利益や市場に悪影響を与えるかどうか

## 補足：ファインチューニング

### 1. 基本の考え方
- **プレトレーニング（事前学習）**  
  大量のデータで一般的な知識を学習（例：BERTやGPT）。  
- **ファインチューニング（微調整）**  
  特定タスクや領域に合わせて追加学習。少量のデータでも有効。  

👉「大辞典を覚えたあと、自社マニュアルで仕上げる」イメージ。

### 2. 主な手法
1. **フル・ファインチューニング**  
   - モデル全体のパラメータを更新  
   - 精度は高いが計算コスト大  

2. **パラメータ効率化ファインチューニング（PEFT）**  
   - 一部のみ更新して効率化  
   - 代表例：  
     - **LoRA（Low-Rank Adaptation）**  
       重み行列を低次元近似して更新  
     - **Prefix Tuning / Prompt Tuning**  
       プロンプト部分だけ追加学習  ---

### 3. 活用例
- **分類タスク**：感情分析、ジャンル分類  
- **QA（質問応答）**：FAQ対応  
- **生成タスク**：レシピ、商品説明、自社文書対応  

### 4. 試験で押さえたいキーワード
- 事前学習済みモデルを **特定用途に最適化**  
- **部分的な微調整手法** によりコスト削減  
- 代表例は **LoRA / Prompt Tuning**

## 補足：ハルシネーション対策とファクトチェック

### 1. ハルシネーション
- **定義**：AIが「もっともらしいが事実ではない情報」を生成する現象  
- **主な原因**  
  - 学習データの誤りや偏り  
  - モデルが不足情報を推測で補完  
  - 知識のない領域で無理に回答

### 2. ハルシネーションを減らす方法
1. **プロンプトの工夫**  
   - 出典を求める（例：「根拠とともに答えてください」）  
   - 「わからない場合は不明と答える」と明示  

2. **追加学習や調整**  
   - 専門データでファインチューニング  
   - **RAG（Retrieval-Augmented Generation）** で外部データを参照  

3. **モデルの選択**  
   - 最新知識を持つモデルを利用  
   - ドメイン特化型モデルを選択  

### 3. ファクトチェックの方法
- **クロスチェック**：複数モデルで回答を比較  
- **外部情報源との照合**：検索・公式文書・論文など  
- **人間による検証**：重要な分野（医療・法律・契約）では必須

### 4. 試験で押さえたいキーワード
- **Human-in-the-loop**：人間による確認が不可欠  
- **RAG**：外部知識を取り込むことで精度向上  
- **対策の三本柱**：プロンプト工夫・追加学習・外部情報活用

## 1. AIの歴史

### エキスパートシステム
- **意味**: 専門家の知識をルールとして組み込み、推論エンジンで解答を導くAI。1980年代に実用化。  

「ルールベース（人が知識を入力）」と「統計学習ベース（データから学ぶ）」の違い

1. ルールベース（Rule-based AI）
知識の獲得方法: 人間の専門家がルールを「手で入力」

2. 統計学習ベース（Data-driven AI）
知識の獲得方法: 大量のデータを使い、統計や機械学習によって自動的にルールを発見

第二次AIブーム → ルールベース型（人がルールを入れる）
第三次AIブーム → 統計学習ベース（データから学習）

### 推論エンジン
- **意味**: 蓄積した知識を使って論理的に結論を導く仕組み。

### 第一次AIブーム
- **意味**: 1950〜60年代。推論・探索を中心とした研究期。

### 第二次AIブーム
- **意味**: 1980年代。エキスパートシステムの商用化が進んだ時期。

### 第三次AIブーム
- **意味**: 2010年代以降。ディープラーニングやビッグデータにより飛躍的発展。

### ディープラーニングの台頭
- **意味**: 多層ニューラルネットワークを活用し、高精度な学習が可能になった流れ。

### ニューラルネットワークの再評価
- **意味**: 過去に停滞していたが、計算資源・データ拡大で再び脚光を浴びた。

### GPUの活用
- **意味**: 行列演算の高速化によりディープラーニングを支えたハードウェア要素。

### ビッグデータの到来
- **意味**: 大量のデータ収集・蓄積がAI学習の基盤となった時代。

### AlphaGo
- **意味**: 囲碁でプロ棋士を破ったAI。ディープラーニング＋強化学習の代表例。  

## 2. 基本用語

### トークナイゼーション
- **意味**: テキストを単語やサブワードに分割する処理。

### 埋め込み表現（Embedding）
- **意味**: 単語や文をベクトルに変換し、意味的な近さを計算できる表現。

### 転移学習
- **意味**: 既存モデルで学習済みの知識を、新しいタスクに応用する学習方法。
- **深掘りメモ**:GPT-2で学んだ「言語理解能力」を、別のタスクに応用
例：質問応答チャットボット

### 微調整（Fine-tuning）
- **意味**: 事前学習モデルを、特定のタスク向けに追加学習させる手法。

### RLHF（人間のフィードバックによる強化学習）
- **意味**: 人間の評価を報酬としてモデルを調整する手法。ChatGPTにも使われている。

### アライメント（Alignment）
- **意味**: AIを人間の価値観や意図に沿うよう調整すること。  
- **深掘りメモ**:  AIは強力な生成能力を持つが、制御されていないと以下の問題が起こることがある
・不適切な発言や差別的表現
・誤情報の生成（ハルシネーション）
・ユーザーの意図に沿わない回答

そこで 「AIの出力を人間の意図に沿うよう制御する」 仕組みとしてアライメントが重要になる

🔹 現代LLMのアライメントの型
1.事前学習モデル＋転移学習
・まず膨大な一般データで事前学習
・基本的な言語理解能力を習得

2.人間フィードバックによる調整（RLHF）
・人間の評価を報酬にしてモデル出力を微調整
・安全で適切な応答に誘導

3.プロンプト設計による制御
・システムプロンプト：モデルの振る舞いを指示
・リファインプロンプト：ユーザー指示を具体化して改善

4.出力後フィルタリング
・不適切な単語や表現を自動でブロック
・モデルのハルシネーションを検知する補助的仕組み

## 3. アルゴリズム

### 勾配降下法（Gradient Descent）
- **意味**: 損失関数の値を最小化するためにパラメータを更新する最適化手法。

### 損失関数（Loss Function）
- **意味**: 予測値と正解の差を数値化する指標。学習の目標となる。

### 活性化関数（Activation Function）
- **意味**: ニューラルネットに非線形性を与える関数。ReLUやSigmoidなど。

### ソフトマックス関数
- **意味**: 出力を確率分布に変換する関数。分類タスクで使用される。

### Attention Mechanism
- **意味**: 入力の重要部分に重みを割り当て、処理を集中させる仕組み。

### Encoder-Decoder構造
- **意味**: 入力をエンコードし、出力をデコードする構造。翻訳モデルなどで利用。


### 自己回帰モデル（Autoregressive Model）
- **意味**: 過去の出力をもとに次の出力を逐次生成するモデル。GPT系列に用いられる。

### Masked Language Model
- **意味**: 文中のマスク部分を予測するモデル。BERTの学習に使われる。

### ビームサーチ（Beam Search）
- **意味**: 複数候補を並行探索し、最適な出力を選択する探索アルゴリズム。
- **深掘りメモ**: 
各ステップで最もスコアの高いトークンを選択する→出力に偏りが出てしまう。
対策：
1.温度調整（Temperature）
2.
Top-k サンプリング: 上位 k 個のトークンからランダムに選ぶ
Top-p（Nucleus）サンプリング:累積確率 p 以下のトークンからランダムに選ぶ
