# 生成AIの実務シナリオまとめ

## 1. 文章生成（Text Generation）
- **用途**：文章作成、要約、翻訳、メール作成、レポート作成  
- **利点**：作業時間の短縮、アイデア出し効率化  
- **リスク**：ハルシネーション、バイアス・不適切表現  
- **実務例**：マーケティング文書生成、FAQ応答、議事録自動要約  

## 2. 画像生成（Image Generation）
- **用途**：広告、デザイン、キャラクター作成、アバター作成  
- **利点**：デザイン作業の短縮、少人数でも多様なビジュアル作成  
- **リスク**：著作権問題、倫理リスク  
- **実務例**：広告バナー生成、ゲームキャラクター作成、アイコン生成  

## 3. 音声生成（Voice / Speech）
- **用途**：音声合成、音声翻訳、ナレーション作成  
- **利点**：音声コンテンツ制作コスト削減、声のバリエーション作成  
- **リスク**：肖像権問題、誤情報音声の拡散  
- **実務例**：教育・広告ナレーション、翻訳音声、多言語ボイスチャット  

## 4. コード生成 / プログラミング補助
- **用途**：コード自動生成、バグ修正、ドキュメント作成  
- **利点**：開発速度向上、定型処理の自動化  
- **リスク**：セキュリティ脆弱性、著作権付きコード生成  
- **実務例**：GitHub Copilotでのコード補完、テストコード生成、定型スクリプト作成  

## 5. データ分析・意思決定支援
- **用途**：レポート作成、データ解釈、未来予測  
- **利点**：データ処理効率化、分析結果の自動可視化  
- **リスク**：バイアスによる誤判断、誤統計情報の提示  
- **実務例**：売上データ自動分析、市場動向レポート作成、BIツール連携での洞察提供  

---

**ポイント**  
- AIは自動化を補助するツールであり、**最終判断は人間が行う**  
- ハルシネーション、バイアス、著作権のリスクを理解して運用することが重要

# 生成AIパスポート対策：プロンプト演習まとめ

## 1. プロンプト設計の基本
- **目的を明確にする**  
  例：「商品の説明文を作成する」「要約して3行にまとめる」
- **役割を指定する**  
  例：「あなたは法律の専門家です」「あなたは英語教師です」
- **出力形式を指定する**  
  例：「表形式で」「箇条書きで」「JSON形式で」
- **Few-shot学習**  
  少数の具体例を提示して出力パターンを学習させる

## 2. リファインプロンプト（出力精度を上げる工夫）
- **不明な場合は回答を避ける指示**  
  例：不明な場合は '不明' と答える
- **出典・根拠の提示を要求**  
  例：回答には必ず参考文献やURLを添える
- **文体・トーンの指定**  
  例：丁寧語で説明する／カジュアルで親しみやすく書く
- **段階的指示**  
  例：
  1. 要約する  
  2. キーワードを抽出する  
  3. 表形式でまとめる

## 3. 実務シナリオ別プロンプト例
- **文章生成**  
  例：あなたはマーケティング担当です。以下の商品情報からSNS投稿用の文章を3行で作成してください。
- **画像生成**  
  例：キャラクターを生成してください。条件: 青い服を着たアライグマ、笑顔、背景は森。
- **音声生成**  
  例：以下のテキストをナレーション用の自然な音声に変換してください。声のトーンは落ち着いた女性。
- **コード生成**  
  例：Pythonで指定されたCSVファイルを読み込み、列ごとの平均値を計算する関数を作成してください。
- **データ分析・意思決定支援**  
  例：売上データを元に、過去3ヶ月の売上傾向を簡単にまとめ、今後の戦略を提案してください。

## 4. ポイントまとめ
- 明確で具体的な指示がAIの精度を大きく左右する
- 出力形式・役割・トーンを指定するだけでも精度向上
- リファインプロンプトで回答の正確性・信頼性を上げる
- 段階的指示により複雑タスクを分かりやすく処理可能
