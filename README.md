# Learning-Notes

## 概要
生成AI技術の習得とポートフォリオ構築を目的とした学習記録レポジトリです。  
フリーの言語モデルの活用やAPI、RAGの活用などを通じてAI基礎理論を体系的に学習しています。  
以下のような取り組みを行っています：
- 日常で使えるAIを活用したアプリのモックの制作
- 特定のドメインに特化したモデルのファインチューニングの実証
- ローカル環境で動作するチャットボットの制作
- ローカル環境×機密情報のチャットボットの実証

---

## フォルダ構成

```

│   ├── notebooks/        # 学習・実験用ノートブック
│   └── notes/            # 理論や実装メモをまとめたテキスト

│

│   ├── articles/         # Web記事やブログのまとめ
│   └── papers/           # 論文PDFやまとめノート
│
├── archive/              # 過去のコードや古い資料
│   └── legacy/           # 古い実装や試作コード
│
