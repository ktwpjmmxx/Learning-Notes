# Learning-Notes

## プロジェクト概要
このリポジトリは、生成AI技術の習得とポートフォリオ構築を目的とした学習記録レポジトリです。  
主に以下の領域を体系的に学習しています：

- GPT-2やGPT系モデルを用いたチャットボット開発  
- Diffusionモデルを中心とした画像生成技術の理解と実装  
- AI基礎理論、ニューラルネットワーク、Transformerの深い理解

---

## 技術スタック
- **言語モデル**: GPT-2, Transformers  
- **画像生成**: Stable Diffusion, DDPM  
- **フレームワーク**: Hugging Face, PyTorch  
- **データ管理・可視化**: pandas, matplotlib, seaborn  
- **環境**: Google Colab, Python 3.11+
